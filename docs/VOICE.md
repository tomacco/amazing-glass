# Voice

How this project talks. Applies to the README, the demo, docs, commit messages and any
text an AI agent writes for this repo.

## The register

Simple, bold, a little funny. Short sentences. Say the thing, then show it.
Talk like an engineer who is proud of the work and slightly amused by it.

- Lead with the claim, then the proof. A number beats an adjective.
- Every claim must survive a five-second check. If a reader can falsify it by opening
  DevTools, cut it or make it exact.
- Humour comes from understatement and plain facts, never from exclamation marks.
- Admit limits in the same breath as the brag. It makes the brag believable.

## Banned

These read as machine-written. Remove them on sight.

| Pattern | Example to avoid | Instead |
|---|---|---|
| Em dashes | "glass — the real kind — on the web" | A full stop. Or a comma. |
| Contrast reframe | "It's not just blur, it's refraction." | "Blur is not glass." Stop there. |
| Rule of three | "fast, beautiful, and accessible" | Pick the one that is true and measurable. |
| Puffery words | delve, tapestry, testament, realm, harness, seamless, elevate, unlock, robust, cutting-edge, game-changer, pivotal, meticulous | The plain verb. |
| Filler hedges | "It's important to note that", "In today's fast-paced world" | Delete the clause. |
| "Serves as" | "The layer serves as a lens" | "The layer is a lens" |
| Stacked connectors | Moreover, Furthermore, Additionally | New paragraph, no connector. |
| Colon reveals | "The secret: physics." | "It uses physics." |
| Emoji as bullets | "🚀 Fast" | Words. |
| Uniform rhythm | Ten sentences of the same length | Mix short and long on purpose. |

Sources for the list: Wikipedia's "Signs of AI writing" guide and 2026 reviews of model
output, one of which found that Claude uses em dashes more than professional writers do.
So this repo uses none.

## Numbers

- Give the unit and the conditions. "Mean error 2.09 on a 0 to 255 scale, two test scenes,
  macOS 27" is a claim. "Pixel-perfect" is not.
- Do not round in our favour.

## Names

- "Liquid Glass" is Apple's name for Apple's material. Use it only to refer to Apple's work.
  Our thing is "amazing-glass" or "the glass".
- Say "not affiliated with Apple" wherever Apple is mentioned at length.
