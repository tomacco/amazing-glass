# Contributing

Thanks for looking. Here is everything you need.

1. `bun install`, then `bun run build`, `bun test` and `bun run typecheck`. All three must pass.
2. Visual change? Attach a before and after screenshot to the pull request.
3. Changed the optics or a preset? Rerun the lab (`lab/README.md`) and put the new error
   numbers in the pull request. A preset without a measurement is a guess.
4. New component? Add its reference to `apps/guide/api.ts`, a live example to the guide, and
   keyboard support.
5. Writing words? Follow `docs/VOICE.md`.

Bugs and ideas go in the issues. Screenshots help more than adjectives.
